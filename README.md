### 🚀 Featured Project

#### 🛍️ [ClothAshe - Backend](https://github.com/pierxromero/ClothAshe-backend)
**ClothAshe** is a RESTful API developed with **Spring Boot**, **Java**, and **MySQL**, designed to manage an **online clothing store** with a focus on scalability, maintainability, and security.  

**Key Features:**
- 🔐 JWT authentication and role-based access control (Admin, Owner, User)  
- 👤 User & Address management  
- 🛍️ Product, Category, Brand, Color, and Size CRUD operations  
- 🛒 Shopping cart and order system  
- 💳 Payment processing  
- ⭐ Favorites and product reviews  
- ❓ User inquiries system  
- 📘 Full Swagger documentation  

**Tech Stack:**  
`Java 17` · `Spring Boot 3` · `Spring Security` · `Spring Data JPA` · `JWT` · `Lombok` · `MySQL` · `Swagger`
